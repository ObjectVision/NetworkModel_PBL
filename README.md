# NetworkModel_PBL

The network model of PBL, the Netherlands Environmental Assessment Agency, computes journeys between origins and destinations by public transport, by car, by bicycle and on foot. It is a configuration for [GeoDMS](https://github.com/ObjectVision/GeoDMS).

The documentation is on the [wiki](https://github.com/ObjectVision/NetworkModel_PBL/wiki). To run the model, start with [How to run the model](https://github.com/ObjectVision/NetworkModel_PBL/wiki/How-to-run-the-model): set up a run in `cfg/main/ModelParameters.dms` and start `batch\UpdateAll.cmd`, which computes everything that is missing.
